# f v5: Adding the f Student's Own Pair Data to f

Status: completed (2026-11-07). The design was fixed before recording; results are in Section 5.

## 1. Motivation

The f v4 training data includes 100 teacher rollouts plus rollouts from the B+tactile student (122) and the proprio-only student (119), but none of the f student's own states. The follow-up check (`DECOMPOSITION_DESIGN_20261105.md` Section 7) showed that on f-student states, f's F1 is 0.03–0.05 lower than on other students, with low recall (0.68). This step adds one round in the spirit of DAgger: add the f student's states to f's training data, retrain the student with the new f, and see whether part of the loss in SuperDex can be recovered.

## 2. Pipeline

Only one thing changes: f's training data gains the f student's pairs. All other settings are the same as f v4.

1. **Recording:** in IG, use the f v4 student (training seed 0, model 783805, student sees the f v4 channel) to record training pool seeds 109/110/111, 64 episodes per seed. The recorder and observation noise are the same as in earlier pair recordings (`isaac` clone 8a2c556, `record.sbatch`, `RECORD_POLICY=student`). Evaluation seeds 42–44 are not used.
2. **Pairs:** `collect_pairs.py`, `penlen=ig`, μ=1.0, each seed split into two segments, 0–32 and 32–64.
3. **Dataset v5:** on top of the v4 split, add `train_f` (seeds 109, 110) and `shift_f` (seed 111, held out).
4. **f v5:** same `train_f.py` settings as f v4 (budget 100, seed 0/1/2, 4000 steps), `extra=train_bt,train_p,train_f`. The student uses seed 0 (consistent with the v4 convention; not selected by validation set).
5. **Student:** new repository `penspin-student-fv5-20261106`, cloned from the penlen repository 1923a67, adding only `f_models/f_v5_tps_b100_s0.pt` and changing the path; environment code unchanged. Training seeds 0/1/2, same DAgger settings as the f v4 student (400 rounds).
6. **Evaluation:** IG protocol evaluation (seeds 42–44 × 64); SuperDex μ=0.5/1.0/1.5 zero-shot, with initial states reused from the evalFB recordings (under the same evaluation seed, all recordings have identical initial states).

## 3. Decision rule (fixed before seeing results)

**Offline:** F1 of f v5 and f v4 on `shift_f` (held-out f-student states) and on the evalFB pairs in `runs/pairs_own` (f-student states on the evaluation seeds). Also check that f v5 does not drop more than 0.01 below v4 on val/shift/shift_p.

**Primary metric:** SuperDex μ=1.0 rotation reward, mean over the 3 training seeds. Let d = f v5 mean − comparison mean, SE = sqrt(sd_v5²/3 + sd_comparison²/3).

| Comparison | Mean±sd | Reading |
|---|---|---|
| f v4 student | 15.9±1.6 | f v5 improves on f v4 only if d > 2·SE |
| Calibration v4 student (current best) | 17.1±0.9 | f v5 beats the best simple baseline only if d > 2·SE |

Anything within ±2·SE counts as "not separable". μ=0.5/1.5 and IG results are supplementary and do not change the primary reading.

## 4. Limitations and reporting basis

- **Budget:** f v5 uses about 128 more f-student rollouts (2 seeds) than f v4, raising the total number of student rollouts from 241 to about 370; budgets become even less equal, and the report must state this.
- **Only one iteration:** the f v5 student's state distribution will shift again; no further iteration is done here.
- **f-student states come only from training seed 0:** recorded with model 783805 only; other training seeds were not used.

**Conclusion:** f's F1 on the f student's own states improved (0.721 → 0.755), but SuperDex reward did not follow. In IG it dropped slightly (24.7 vs 25.7). The IG-to-SuperDex loss is 9.4, vs 9.7 for f v4, essentially unchanged. So at the current accuracy, f's error on its own student's states does not explain the f student's IG-to-SuperDex loss. The remaining loss more likely comes from the dynamics gap, or from tactile differences that F1 does not measure (for example contact force magnitude and timing). This inference only rules out "f is inaccurate on its own student's states"; it does not by itself prove the cause is dynamics.

**Reporting basis:** the gap to the calibration student exceeds 2·SE, but the rule only pre-defined the "improvement" direction. Each group has only 3 training seeds, and the sd itself is unstable, so this is written as "f v5 does not improve and is below the calibration student", not as "f v5 is significantly worse".
